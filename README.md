# Search - CS50 Web Project

A front-end clone of Google Search, Image Search, and Advanced Search pages, designed using only HTML and CSS. The project focuses on layout precision and user interface styling.

---

## Features

- **Google Search Clone:** Replicates Google’s main search interface.
- **Image Search:** Redirects to Google Image Search results.
- **Advanced Search:** Includes filters for phrase, exclusion, and site-specific searches.
- **Responsive Design:** Adjusts seamlessly for desktop and mobile screens.

---

## Technologies Used

- HTML5
- CSS3
